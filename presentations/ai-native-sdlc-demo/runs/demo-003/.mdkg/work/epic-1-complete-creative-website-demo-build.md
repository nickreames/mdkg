# Goal

Coordinate a full creative website demo run from a sealed semantic source and
binding through local work, caller-authorized integration/publication,
production verification, and truthful closeout.

# Scope

- Creative direction in `spike-1`.
- Portable static Astro and zero-client-JavaScript implementation in `task-1`.
- Build, browser, no-secret, and claims validation in `test-1`.
- Thin caller-owned canonical integration in `task-2`.
- Build-once serial canonical validation in `test-2`.
- Externally authorized bounded normal publication in `task-3`.
- Exact-SHA READY deployment and public-route verification in `test-3`.

# Milestones

- `spike-1`: choose audience, offer, structure, and art direction.
- `task-1`: build the complete static local site.
- `test-1`: validate the candidate.
- `task-2` and `test-2`: integrate and validate only under a caller lease.
- `task-3` and `test-3`: publish and verify only under matching human
  authority.

# Out of Scope

- Vercel project creation.
- Self-authorized shared-source integration, commit, push, or deployment.
- DNS, aliases, durable hosting, push, tag, publish, or analytics activation.

# Risks

- Creative output becomes generic or too close to an existing page.
- Site copy overclaims mdkg capabilities.
- Raw prompts or private context are retained.
- Binding, source, interface, seal, lease, or authority identity drifts.
- Shared-output checks race or duplicate builds.
