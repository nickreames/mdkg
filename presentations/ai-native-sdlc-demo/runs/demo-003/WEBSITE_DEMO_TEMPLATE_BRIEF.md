# Website Demo Template Brief

Build a complete, differentiated website candidate from this mdkg graph.

The result should be a local website that can be reviewed, discarded, polished,
or handed back to its caller for a separately authorized integration decision.

## Required Story Beats

- Start from `goal-1`.
- Use `spike-1` to choose audience, offer, website structure, visual direction,
  animation ideas, and interaction ideas.
- Use `CREATIVE_PRODUCTION_INTAKE.md` when Creative Production is available, and
  record only a compact public-safe direction summary.
- Use static Astro for implementation.
- Emit semantic HTML and CSS with zero client-side JavaScript.
- Use `DESIGN.md` as the Ocean Flow baseline.
- Build a complete local website candidate.
- Validate with `test-1`.
- Close with a recommendation: discard, rework, or hand the accepted local
  candidate back for a separate integration decision.

## Creative Freedom

The run may produce different website ideas each time. It can change the
message, structure, visual rhythm, CSS-only motion, static proof sections, and
layout as long as it preserves the fixed constraints.

Creative Production may help explore Positioning, Mood boards, Offers, Scenes,
Ads, Shots, or later Assets. The selected direction should make the final site
more differentiated, not merely more decorative.

## Fixed Constraints

- Ocean Flow design baseline.
- Static Astro with zero client-side JavaScript.
- No `client:*` directives, hydration metadata, generated JavaScript, inline
  runtime scripts, remote fonts, or third-party runtime assets.
- Public-safe mdkg claims.
- No secrets, raw prompts, provider payloads, credentials, or private repo data.
- No integration, commit, deployment, DNS, analytics, durable hosting, npm
  publish, or git push by default.
