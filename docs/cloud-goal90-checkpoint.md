## Behavior and decisions

Optional `--graph <name>` selects a registered existing independent project root
containing its own `.mdkg`. Without it, the default root remains unchanged. Names
are exact lowercase aliases; paths, numeric and UUID selectors are unsupported.
Relative paths, config, memory, ID allocation, caches, locks, state, events,
goals/claims/loops, DB/queues/snapshots, scratch and both native mirrors belong to
the selected root. MCP binds its session to that root. Selection is identified
on stderr, preserving command JSON stdout.

Registration/removal are explicit host-level hash-bound previews and applies.
The ignored/untracked local registry requires a valid Git work tree. Bindings
reuse canonical-v2 or proven0.6.2 working-host IDs. Unknown/changed/foreign/copied
bindings, overlapping roots, links and host mirror collisions refuse. Removal
preserves every graph file and ignore entry. No discovery, migration, merging,
copying, deletion, sticky selection, federation or transport platform is added.

Private named selection permits local/private output and refuses public/internal
visibility, public bundles and graph transport. All named outputs stay inside
the selected root. Default dispatch never loads the registry or private graph.
Named admission reads bounded host ownership/ignore/index metadata and only the
requested root. Git history remains shared with the host repository; selection
and ignore rules provide no Git/filesystem access control or backup guarantee.
Existing one-writer and deferred hostile-ancestor/ACL limits remain unchanged.

The exact contract and test scope are in [design](cloud-goal90-design.md),
[validation plan](cloud-goal90-validation-plan.md) and
[intervention log](cloud-goal90-interventions.md).
