   coverage floors, packaged guidance/skills/contracts, independent current-source

   site profiles remain repository/website checks owned by paused Epic258. Hosted
   CI remains honestly unqualified under Epic257 and does not block local0.6.0
   package acceptance. No hosted dispatch is authorized.
3. Retain macOS and Linux ARM64/x86_64 qualification; identify native/emulated
   execution. Node >=24.18.0 <25 is supported with capability admission; older24
   and higher majors must refuse before effects. Windows remains unqualified.
4. Reuse complete applicable same-input evidence. A missing final seal does not
   erase current case passes. Separate package-input from harness-input identity;
   admit retained exact bytes without replacing the original artifact/capture.
5. Keep Bugs46/47 deferred and unresolved under Goal87. Historical ambiguous
   migration references receive an evidence-bound unsupported disposition, never
   fabricated identity. Dec99 governs current security evidence; blocked historical
   scan context must not be accessed, recovered or rerun.
6. One writer on main, supported claims/transient locks and explicit-path local
   commits after validation are authorized. No remote Git, push, tag, publication,
   providers, deployment, root/consumer changes, canonical branch/worktree change,
   graph migration or bundle/subgraph refresh. Selected Goal73 and protected state
   remain unchanged. Goal85 stays paused even after qualification.
