# Purpose

Retain the legacy human-profile entrypoint for existing links and local notes.
The one-release legacy alias remains available in this compatibility release.

# Scope

Read [COLLABORATION.md](COLLABORATION.md) for current shared preferences. This
file need not be loaded when it contains no additional project-specific notes.

# Requirements

Preserve customized content during initialization and upgrades. Moving legacy
notes is a reviewed project decision, not an automatic scaffold operation.

# Validation

Check that retained links and local preferences remain usable after an upgrade.
