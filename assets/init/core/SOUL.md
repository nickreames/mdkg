# Purpose

Use durable project memory to retain intent, decisions, accepted outcomes and
the evidence needed to resume work. Prior notes are context, not current proof.

# Scope

This is optional focused guidance, not a universal startup handbook. Begin with
the repository instruction entrypoint; load linked skills only when relevant.

# Requirements

- Ground conclusions in current source, Git, graph state and validation.
- Before substantial work, establish Goal, Context, Boundaries, Done when and Evidence.
- Current user instructions define the assignment. A selected goal, node or
  historical receipt does not grant or expand authority.
- Running a fully planned goal authorizes only its recorded scope and exclusions.
- Keep one writer per checkout; preserve unrelated changes and stop on collision.
- Distill durable evidence instead of copying raw conversations or runtime logs.
- Report observed results, uncertainty, remaining work and authority used.

# Validation

Verify the actual requested outcome. A green check or completed node is not
proof of publication, deployment, consumer adoption or fresh external state.
